# 多帕练习 — 公开版规格说明

多帕练习是一款浏览器游戏：每做对一道计算题，吉祥物的动作、画面演出和音乐都会放大。本文面向游玩的人、家长，以及关心开发与改动的人，说明当前实现的行为。数值以后可能会调整。

## 1. 概要与设计思路

目标是每天做一点计算，并能确认自己比过去有没有成长。基础题即使超过时间也能继续，全部做完就是 100 分。没有游戏结束。

答错会显示「差一点」，可以重新作答。已经得到的星星、奖杯和演出，不会因为失败或没来玩而被收回。连续记录有补上休息日的办法；成长对比只显示变好的项目。奖励在达成条件时解锁，没有抽奖，也没有付费获得。

界面是简体中文，既适合小学生练习计算，也适合大人使用。以手机竖屏为主，电脑上也可以用鼠标和键盘操作。不需要注册账号。记录按浏览器分别保存，不会自动同步到别的设备。

## 2. 画面与流程

### 2.1 画面一览

| 画面 | 内容与主要操作 |
| --- | --- |
| 标题 | 标志、多帕吉、我的等级、紧挨在下面的复习、1～6 年级、技能树、奖杯、收藏、任务、日历、设置、？ |
| 游戏 | 题目、输入格、专用数字键盘、做对的题数、差一点的次数、时钟、多帕、连击、进度显示、静音 |
| 基础结果 | 100 分、用时、一次做对率、多帕、成长、技能和任务的结果。达成条件时可以进入加时赛、重做错题、再来一次、回标题 |
| 最终结果 | 包含加时赛的得分和多帕、做对的题数、差一点的次数、任务、重做错题和回标题 |
| 技能树 | 前置关系、解锁、练习、精通的状态、星星、生疏、技能说明和练习、删除部分记录 |
| 奖杯 | 按分类和系列列出的成就、获得日、条件和奖励、筛选、即将获得的成就 |
| 收藏 | 试看、试听已解锁的演出，每个分类可以固定，也可以随机 |
| 设置 | 题数、声音、音量、动作强度、演示、重置全部数据 |

通常按「标题 → 基础题 → 基础结果 → 可选的加时赛 → 最终结果」进行。复习只到基础结果。结果画面的操作按钮固定在下端，成长记录变多时也能进入下一步。

### 2.2 初次引导和「？」帮助

第一次会显示 5 页引导。顺序是：导入、我的等级、年级、技能树、推荐我的等级。设置按钮下面的「？」可以再看一遍加上奖杯和收藏的 7 页说明。

说明对象会用聚光灯照亮，必要时会滚动。说明文字显示在独立卡片上，多帕吉用移动、指点和表情来引导。不会把说明写成多帕吉的台词。最后会指向「我的等级」和「？」，如果不能同时放进画面，卡片里会显示同一个问号图标。

用「下一步」「返回」「跳过」，以及最后的「开始！」来操作。Enter 和右箭头是下一步，左箭头是上一步，Escape 是跳过，Tab 在引导内移动焦点。按暗幕不会关闭，引导进行中不能操作背景按钮。

看到最后和跳过都会记成已显示。初次引导之后，按补签锤、登录奖励、奖杯通知的顺序处理。全部重置后会再次显示初次引导。演示中，以及一部分确认用 URL，不会自动显示。

## 3. 模式

### 3.1 我的等级

第一次是「水平测试」。按年级、前置关系的深度排列技能往下走；一次做对的话，出题对象和它的前置技能会一起变成精通、☆1。移动幅度一开始是 6，做对后把当前幅度的 1.3 倍向上取整，最大 12；答错后把一半向下取整，最小 1。答错后会回到最后一次做对的位置之后的范围。基础题结束就记成已测试。

之后的出题按前置关系的深度、年级、技能定义顺序来选。从已精通的末尾 6 个技能里选复习，复习名额是 `min(候选数, max(1, round(题数 × 0.3)))` 题。优先生疏的技能，剩下的从候选里随机选。没有已精通的技能时，复习名额是 0。

其余部分按顺序重复已解锁、未精通的前 4 个技能。如果全部精通，就从全部已精通的技能里选。加时赛重复未精通候选的末尾 3 个技能；没有的话，重复已精通的末尾 3 个技能。刚测完之后的加时赛，从已解锁、未精通的开头选。

### 3.2 年级

不管有没有解锁，都从所选年级的技能出基础题。从浅到深的前置关系排列上会加上随机晃动。答题结果也会记入通常的熟练度。

加时赛重复该年级技能列里 `floor(技能数 × 0.55)` 以后的部分，不切换到下一个年级。

### 3.3 练习

从技能树选择已解锁的技能来练习。已经精通的话，可以从说明画面开始练习。基础题用这个技能；加时赛从这个技能直接前置的、已解锁的技能里选。没有对象就继续同一个技能。

年级和练习里，满足条件的时光胶囊有时会替换基础题中的 1 题。年级模式只从该年级及更低年级的技能里选，所以不会超出所选年级；练习里这一题可能超出所选的技能范围。

### 3.4 复习

含有答错的题目，在做到最后时，会把题目本身最多保存 40 题。用题目标题和算式作标识来去重。中途中断的未完成题不会加入。

可以从标题和结果上的重做错题按钮开始。从已保存列表的末尾选取，上限是设定题数和 10 里较小的那个。即使从结果按钮开始，也不只限于这一轮答错的题，而是使用以前留下来的列表。

一次做对、重新做完的题目会从列表删除；再次答错的题目会留下。全部做完就是 100 分，没有加时赛。也会记入通常的成长记录、熟练度和任务。

### 3.5 演示

用设置里的「自动看一遍」开始自动操作。从全部技能选出题目，按从易到难排列；加时赛从 4 年级及以上的技能里选。使用通常的输入、判定和演出，也会放入答错。基础部分答错题数的上限是 `floor(题数 × 0.2)`。

基础、加时赛、最终结果走完一圈就回标题，并解除演示。点一下或按键也可以结束。开始后马上点屏幕，有 600ms 的忽略时间。演示的游玩结果不计入历史、熟练度、复习和成长统计，也不推进任务和奖杯。回到标题后，会进行通常的登录处理。

固定的演出在演示里也会使用，只有随机的分类会从已解锁的里面选。URL 的 `?demo` 是和这个自动操作不同的功能。

## 4. 一次游玩与输入

### 4.1 基础题与加时赛

题数是 6、10、14 题，初始值是 10 题。基础的目标时间是 `ceil(题数 × 18 ÷ 10) × 10` 秒：6 题 110 秒，10 题 180 秒，14 题 260 秒。超过也能继续，不扣分。基础的经过时间从开始玩到做完，包含切题。

「做对」是做到最终答案的题数，「差一点」是已接受的数字对当前格子来说是错的次数。「一次做对」是连中间输入在内一次都没有答错就完成的题。基础的一次做对数除以题数达到 0.8 以上，就可以选择加时赛。

加时赛默认 90 秒。开始处理的时刻加上 90,000ms 和导入用的 900ms，作为期限。不是从第一次可以输入的时刻起保证 90 秒，切题时时钟也在走。确认对话框期间会停止。时间到就确定得分，进入最终结果。未完成的题不得分，但已经接受的正确格子增加的多帕会留下。

### 4.2 数字输入

用专用数字键盘和电脑数字键一位一位输入，当场判定。没有确认答案的按钮。正确的位数会保留，错误的数字会在下一次输入时被替换。Backspace 是删掉当前错误数字的操作，不会撤销已经做对的位数。

答题格不限于数字：比较大小填 `<`、`=`、`>`，判断题填 `√`、`×`。数字键盘按当前题目需要的字符切换，编号 1 起对应键盘上的第 1～3 个键，电脑上也可以直接按这些字符。

手机上会按包含浏览器操作栏的显示区域，调整题目空白和数字键盘的高度。包含 0 和删除的最下一排放在底部安全区域之上；画面尺寸变化时，题目的字号也会重新计算。

| 题目形式 | 输入顺序与自动显示 |
| --- | --- |
| 横式 | 从答案左边的位数开始输入 |
| 横式有余数的除法 | 先商，后余数 |
| 加减竖式 | 从最低位开始。进位、退位的辅助数字自动显示 |
| 乘法竖式 | 从右边输入部分积；有多个部分积时，合计也从右边输入 |
| 除法竖式 | 按商的高位、减得的差、下一个商的顺序。积、落下来的数字、最后的余数 0 自动显示 |
| 小数 | 小数点自动显示，只输入数字 |
| 分数 | 先分母，后分子。带分数按整数部分、分母、分子的顺序 |
| 比、含字母的式子、近似数、百分数 | 从指定空格的左边位数开始输入 |
| 填方框、数字天平、数位、单位、时间、估算、找规律 | 只填空着的方框，从左边开始；时间先时后分 |
| 比较大小 | 只填两边的比较符号 |
| 判断题 | 只填 `√`（对）或 `×`（错） |
| 加减乘竖式的填缺数、找错 | 只填被遮住或写错的那一位 |
| 加减竖式的数字谜 | 遮住 2～4 个数位，点哪格先填哪格；从低位开始也能做对 |

竖式的加减乘会换一种问法出现（约三成）：**填缺数**把算式算完并显示结果，遮住其中一个数位；**找错**把结果中的一位故意写错，要求学生改正这一位；**数字谜**遮住 2～4 个数位，其余照常显示，按任意顺序填。填缺数和找错都只剩一个答题格，正确答案唯一；数字谜的空格在**每列至多一个**，从右往左逐列推时进位（借位）总已知、每列只有一个未知数，所以解也唯一。除法竖式不参与这三种问法：它的中间行重复编码同一批数字，遮一位会在多处被读出来。带小数点的竖式只有找错参与。

数字谜的答题格可以点选：点一个空格就先填它，已填的格点不出反应；换格时未确认的错数字会被丢掉，和 Backspace 一样。进位、退位的辅助数字不显示，推它们是题目的一部分。

分数按准备好的答案形式判定。3 年级同分母分数保留原来的分母，接受不约分的答案。其他分数计算使用生成出来的最简分数、带分数形式。不是让人自由输入等价的另一种写法再判定。

### 4.3 答错与提示

错误的数字使用紫色虚线框。同一格答错 2 次，如果定义了应该看的数字，就会强调并指出来。第 3 次以后会显示计算的中间式、相关的乘法口诀等提示。提示里有时会包含相当于答案的值。

答错时连击变成 0，但不减少得分和多帕，演出阶段和背景音乐保持。为了答错音，背景音乐会暂时压低，并使用弹跳音效和多帕吉恢复的动作。

## 5. 得分、多帕、连击

### 5.1 得分

基础做完是 100 分。把加时赛完成的题从 0 开始记为 `k`，那一题的加分是 `10 + 5 × k` 分。加时赛完成 `n` 题的合计得分是：

```text
100 + 10 × n + 5 × n × (n − 1) ÷ 2
```

5 题 200 分，10 题 425 分，15 题 775 分，23 题 1595 分，30 题 2575 分。得分没有固定上限。连击、答题速度、差一点的次数都不会让得分乘倍或扣分。

### 5.2 多帕的计算

多帕是演出用的数值，和得分分开。内部值 `L` 是常用对数，显示值的底是 `10^L`。开始玩时 `L = 0`。

基础的基准曲线是 `B(f) = 2.3 × clamp(f, 0, 1)^1.15`，加时赛的基准曲线是 `X(n) = 2.3 + 3.0 × (1 − exp(−n / 10))`。

设基础总题数为 `N`，已完成题数从 0 开始记为 `q`，当前题的答题格数是 `m`，这次做对的格子从 1 开始记为 `s`，这次输入的基准增量是 `B((q + s/m)/N) − B((q + (s−1)/m)/N)`。设加时赛已完成题数为 `k`，一格的基准增量是 `(X(k+1) − X(k))/m`。

做对时先把连击数 `c` 加 1，再用下式反映这次输入。

```text
倍率 M(c) = 1 + (2 − 1) × min(1, max(0, c) / 20)
新的 L = min(9.08, L + max(0.003, 基准增量) × M(c))
```

10 连击是 1.5 倍，20 连击以上是 2 倍。上限是对数值 9.08，原来的显示值正好是 `10^9.08`。增量有最低值 0.003，所以不能只从基准曲线的终点决定实际到达值。第一次做对也是 1 连击、1.05 倍；加时赛开始时连击回到 0，多帕会接着算。

显示时，不到 1 万的四舍五入成整数，之后加上「万」「亿」等。单位内的值不到 10 就显示到小数第 1 位，10 以上就显示截断后的整数。到达 100、1000、1 万、10 万、100 万、1000 万、1 亿时有节点演出。通常游玩的上限到不了兆以上。

### 5.3 连击的时间与显示

每个正确的答题格加 1 连击，跨题保留。2 连击以上才显示，20 连击以上显示「多帕×2 MAX」。答错或时间到就回到 0。不过，当前实现里，1 连击的状态不在时间到的判定范围内。

年级 `g` 的普通格子时间是 `3000 + 600 × (g − 1)` ms，题目的第一格再加 2500ms。年级收在 1～6，不明时按 3 处理。

| 年级 | 普通格子 | 题目的第一格 |
| --- | --- | --- |
| 1 | 3000ms | 5500ms |
| 2 | 3600ms | 6100ms |
| 3 | 4200ms | 6700ms |
| 4 | 4800ms | 7300ms |
| 5 | 5400ms | 7900ms |
| 6 | 6000ms | 8500ms |

在可以接受输入的时刻设定期限，切题和确认对话框不消耗时间。剩余时间条在不到 30% 时会强调。10、20、30、50、75 连击，以及 100 以上每 50 连击，会大大庆祝一次。5 连击以上中断时，会短暂显示结束时的数字。

## 6. 出题范围与技能树

### 6.1 范围与生成

计算分成 102 个技能。按年级是 1 年级 15 个、2 年级 17 个、3 年级 24 个、4 年级 18 个、5 年级 17 个、6 年级 11 个。系列是「加减法」「乘除法」「小数与分数」「其他」这 4 个。全部技能的名字、标识、前置、生成条件汇总在 `docs/curriculum.md`。

对象包括四则运算、带中间输入的竖式、小数、分数、近似数、约数与倍数、运算顺序、解方程、分数混合运算、大数改写、百分数（含互化、求百分率）、相等的比（含求比值、解比例）、字母的值，以及比较大小、判断题、单位换算、时间计算、估算、找规律、填方框、数字天平、数位与组成。不出图形、图表、应用题、汉字数字输入；单位换算和时间计算只做数值换算，不画测量图。

同一个竖式技能会以四种问法出现：直接算、填缺数、找错、数字谜（见 4.2）。四者共用同一份布局，`app/js/problems.js` 的 `applyStyle` 只换答题格，不重新排版；数字谜的答题格没有固定顺序，判定顺序由 `app/js/input.js` 的游标决定，两种模式的已填格数是同一个进度来源。

每次按技能条件用随机数生成。用最近 24 题的签名，以及这一次游玩中已经出过的签名，来避开重复。候选生成有重试上限，所以候选少的技能等情况下可能会重复。时光胶囊和复习是为了再现同一道题的例外。

### 6.2 显示与解锁

每个系列分成 2 列，一共 8 列显示；窄画面可以纵横滚动。优先按年级排列，5、6 年级放在 1～4 年级下面。前置关系的线会绕开其他节点，只是排在同一列并不表示依赖关系。

没有前置的技能一开始就解锁；有多个前置时，需要全部精通。状态区分锁定、新的、练习中、精通。通常的精通条件是至少有 6 题历史，并且最近 6 题里 5 题以上一次做对。一旦精通，答错也不会退回去。水平测试的一次性授予是这个次数条件的例外。

### 6.3 技能的星星

精通后按顺序获得 ☆1～☆5。必须一阶段一阶段满足条件；如果已经满足，同一次判定可以升多个阶段。合计最大是 460。

速度判定使用每题答题时间除以基准时间的比率。基准时间是 `第一格的连击时间 + max(0, 答题格数 − 1) × 普通格子的连击时间`。只从对象里一次做对的题目求比率的中位数。

| 星 | 条件 |
| --- | --- |
| ☆1 | 已精通 |
| ☆2 | 做完最近 20 题，一次做对率 0.9 以上 |
| ☆3 | 做完最近 10 题，其中 5 题以上一次做对，时间比率的中位数在 1 以下 |
| ☆4 | 最近 3 题全部一次做对，每题的日期都在获得 ☆3 的 7 天以后 |
| ☆5 | 做完最近 20 题，一次做对率 0.95 以上，时间比率的中位数在 0.6 以下 |

☆4 的 3 题不限于同一天。星星不会因为通常游玩或休息而减少，删除技能记录和全部重置时会消失。说明画面会显示下一颗星的条件、当前值、做过的题数、最短答题时间。

### 6.4 生疏

已精通、并且从最后一次做对起经过 `21 × 86400000` ms 以上的技能成为候选，按从旧到新最多给 3 个显示「生疏」。没有一次做对的日期时，按水平测试授予日期、精通日期的顺序取用。

生疏的技能一次做对 1 题就会重新巩固，星星保留，标记消失。巩固之后，别的更旧的技能可能会变成显示对象。用于我的等级的复习，以及巩固任务。

### 6.5 删除技能记录

有记录的技能长按 600ms，或者聚焦后按 Delete，会打开确认。从按下的位置移动超过 10px，就中止长按操作。

确定后，会删除这个技能，以及直接、间接依赖它的技能的记录和星星。所选技能如果前置还在，就回到新的；前置不齐，就回到锁定。历史、复习、累计统计、奖杯、收藏、已完成水平测试的状态会保留。

## 7. 持续玩下去的机制

### 7.1 历史、日历、登录奖励

在基础结果保存历史，加时赛结束后更新同一条历史的得分、追加做对数、差一点、多帕。最多保留 3000 条。日历显示每天的最高分和游玩次数，可以从日期打开详情。可以移到过去的月份，不能进到未来的月份。

连续天数以今天为起点；今天还没玩的话，以昨天为起点。也会显示最长记录和登录贴纸的张数。游玩日和登录日是分开的，只打开标题不会变成玩过的日子。

登录奖励按设备日期每天 1 次。以星星、爱心、花、音符、三叶草、红花、王冠的 7 日周期领取贴纸。中间夹着没有补签的缺席日，周期就从头重数。贴纸在打开显示的时刻就算已领取，关掉或重新加载，同一天也不会重复领取。

### 7.2 补签锤

1 把可以把没来玩的 1 天记成补签，把游玩和登录的连续接上。不会把那一天加进游玩天数，也不会补上休息日的贴纸。初始持有 1 把，持有上限 3 把。

最后一次来玩在最近 7 天以内，到昨天为止空出来的日子能用持有数全部补上，并且能保住 2 天以上的连续时，标题上每天会提议使用 1 次。拒绝的那一天不会再提议。使用后会在日历上盖补签章。使用历史最多 50 条。

### 7.3 每日任务

根据设备日期，以及当天选取时的记录，决定 2 个简单的和 1 个费事的，然后保存。同一天即使改了设置也不会重选。日期变化后的更新处理会换成新的列表。候选是固定的 11 种，外加 1 种随生疏变化的。

| 名额 | 候选与达成条件 |
| --- | --- |
| 简单 | 做完 1 次、5 连击、一次做对 5 题、复习 1 题、新的技能 1 题 |
| 费事 | 进入加时赛、加时赛 5 题、20 连击、做完 2 次、用年级做完 1 次、新的或练习中的技能 10 题、指定技能一次做对 3 题 |

没有复习、新的对象时，会去掉对应候选。加时赛相关的条件是最近 5 条历史里有加时赛记录；20 连击的条件是 `题数 × 平均答题格数 >= 26`；练习中 10 题的条件是已完成水平测试，并且有未精通候选。同一天不会叠相同指标的任务。

所需时间的筛选模型把 1 次算成 `(题数 × 18 + 预计加时赛时的 90 + 30) / 60` 分钟。一次做对 5 题按 `ceil(5 / (题数 × 0.7))` 次，练习中 10 题按 `ceil(10 / (题数 × 0.6))` 次，20 连击按 2 次来估计。复习按最多 10 题计算，叠上各模式都能达成的项目，选出合计 15 分钟以内的组合。这是估计，并不限制实际所需时间。

巩固候选：有生疏的日子，日期派生的随机数小于 0.5，并且最近 7 天提示过的次数少于 2，就会成为选择对象。可以从标题开始练习对象技能；达成需要同一个技能一次做对 3 题。和生疏本身消失的那 1 题条件不同。

进度在游玩中累加，达成时在画面上端通知。复习也会加进共同的做完、一次做对、连击条件。3 个全部达成时，当天只领取 1 次、1 把锤子，并在日历上做标记。已经到持有上限的话只有演出，奖励不会留到以后。

### 7.5 和上次比

基础结果里，把比同一技能以前的记录有进步的点，作为「进步啦！」最多显示 3 行。这次和比较对象双方都需要 3 题以上。比较对象是上次来玩的日子、21 天以前最近的一天、最初做对的 3 题。不会只拿同一天里过去的那一次当比较对象。

答题时间按每个答题格的平均来比，显示时换算成这次平均格数下的每题秒数。时间缩短 10% 以上，或一次做对率提高 10 个百分点以上的项目成为候选。每个技能选改善最大的 1 个，整体按改善从大到小显示。没有改善就不显示。水平测试、演示、停止成长记录的确认用 URL 不在对象内。

### 7.6 时光胶囊

从每个技能保存的最初 3 题里，选择已精通、从做对时起经过 `30 × 86400000` ms 以上、还没用过的题目中最旧的一个。年级模式只在该年级及更低年级的技能里选；我的等级和练习不做年级限制。

通常的我的等级、年级、练习的基础套题在 4 题以上时，替换从 0 开始的 `max(1, min(N−2, floor(N/2)))` 那一题。水平测试、复习、加时赛、演示、停止成长记录的确认用 URL 不在对象内。一天最多 1 题；预告结束时的日期会被保存，所以之后即使中断，同一天也不会再提示。题目完成时记成已使用。

用信封预告和橙色边，让人看得出是过去的题目。比较时，这次的时间不到过去的 0.95 倍就显示时间缩短；否则显示答错次数减少；两者都没有，就显示又做出来了，并显示日期。正好缩短 5% 时，不会显示时间缩短。

## 8. 多帕吉、演出与声音

多帕吉原则上不说话。造型基准是 `docs/dopakichi.svg`。有大的横耳朵、横向宽的圆头、奶油色的脸和肚子、双层圆眼睛、细手臂和蓝脚。基本色是粉色 `#FF97BF`、奶油色 `#FFF3E4`、耳朵内侧 `#FFE6F0`、蓝色 `#2F79F7`、轮廓 `#000000`。

输入的数字用空着的手搬。左右手可以分别搬不同的数字，判定和搬运分开，不会让下一次输入等待。中间做对、最终做对会用跳跃、拍手、旋转等；答错会先散开再恢复。答错动作有 10 种：序盘 4 种，中盘 8 种，强度 0.6 以上从 10 种里选，并避开和刚才相同的。

基础题号从 0 开始记为 `i`，题数记为 `N`，演出强度是 `E = 0.08 + 0.92 × (i/(N−1))^1.3`。只有 1 题时 `E = 1`。加时赛对完成数 `k` 使用 `tier = floor(k/3)`、`E = 1 + min(0.5, tier × 0.1)`。

按强度叠加背景、红花等做对标记、彩纸、星星、烟花、硬币、观众、行进、还差一点、电饰、晃动。终场从巨大多帕吉、烟花表演、火箭、游行里选，最后显示 100 分。保持输入和数字键盘的位置，以及竖式数位的对应。

音乐和音效用 Web Audio API 合成，不读取外部录音素材。在基础的马林巴进行曲之外，加上 8 位机、庙会配乐、铜管乐队、电子，一共 5 首。使用振荡器、噪声、滤波器和混响等，分阶段叠打击乐、低音、和弦、旋律。

基础速度是 `112 + min(1, E) × 16` BPM，通常开头是 113.28 BPM，最后是 128 BPM。最后一题从基准升高 2 个半音。加时赛是 `134 + tier × 5` BPM，调从基准升高 `2 + min(tier, 5)` 个半音。转调有上限，速度没有这个式子以外的固定上限。

按键、数字落地、做对、答错、多帕的节点、时钟等用声音补充，音高和曲子的和弦同步。开始出声使用浏览器要求的用户操作。背景使用 WebGL，不可用或上下文丢失时切换到 CSS 背景。

## 9. 设置与无障碍

| 设置 | 内容与初始值 |
| --- | --- |
| 题数 | 6、10、14 题。初始值 10 题 |
| 声音 | 开／关。初始值开。也可以从游戏画面的静音更改 |
| 音量 | 0～100%。初始值 80% |
| 动作强度 | 0～100%。未设置时，如果设备指定减少动态效果就是 0%，否则是 100% |
| 演示 | 自动操作显示一圈 |
| 全部重置 | 确认 2 次后，把设备内的数据初始化 |

动作强度会反映到粒子量、晃动、闪光、背景、观众、多帕吉的大动作。0% 时停掉主要的移动、晃动、闪光，引导也变成静止姿势。但这不是停止全部绘制的功能，通常画面的呼吸等和少量粒子的处理会留下。操作数值时，可以在设置画面试反应。计算的判定和得分规则不变。

Escape 会关闭打开的对话框；不在标题时，会打开「回到标题？」的确认。初始焦点是「继续」。确认中会停掉输入、基础经过时间、加时赛和连击的期限、每题的计时。中断前已完成题目的熟练度等会留下。基础结果之前的话，不会创建做完历史。演示中的 Escape 是结束演示。

准备了按钮的无障碍名称、焦点显示、数字以外的标签、引导内的焦点循环。这并不保证只用屏幕阅读器就能完整游玩，也不保证所有设备上的操作性。

高度 700px 以下时，会调整题目纸、演出区域和空白，把数字键盘最下一排放进画面。矮画面也保持按键高度 48px。

全部重置的第 1 次用「全部重置」说明会删掉的内容，第 2 次用「真的要删除吗？」确认不能恢复。两者的初始焦点都是「取消」。取消、Escape、点背景都不会删除。第 2 次确定时，删除所有前缀为 `dopa-drill` 的保存键，丢弃内存缓存并重新加载。无关的键会保留。

设置、历史、熟练度、星星、成长记录、奖杯、收藏选择、贴纸、任务、道具、初次引导状态都是初始化对象。重新启动时，会重新做出初次引导和初始道具等。浏览器拒绝删除时，处理也不会以异常结束，但不能保证已保存的数据被消去。

## 10. 保存与隐私

保存位置是浏览器的 localStorage，键是 `dopa-drill:v1`，数据版本是 1。没有输入名字等个人信息的栏，应用也不会把学习记录发送到服务器。没有广告、外部分析、排行榜、设备间同步。从分发服务器取得游戏的静态文件来运行。

保存区域不能用、读取失败、JSON 损坏时，以初始状态启动；即使保存失败，当场的游戏也会继续。浏览器清除数据、保存限制、换浏览器或换分发来源时，记录不能继承。

| --- | --- |
| 设置、引导 | 题数、声音、音量、动作、引导已显示 |
| 做完历史 | 最多 3000 条。日期、模式、得分、做对、差一点、基础用时、多帕、加时赛 |
| 技能 | 最近 6 题的一次做对、最近 24 个签名、最近 30 题的时间、格数、答错、日期、最近 60 天的汇总、最初 3 题本身、最后一次做对和精通的日期时间、星星 |
| 复习 | 最多 40 题的题目本身 |
| 累计统计 | 完成的题和格子、一次做对、答错、基础做完与模式、基础用时、最大多帕、加时赛、最大连击、复习、来玩的日子、巩固次数、比较与胶囊 |
| 持续、奖励 | 贴纸、登录日、补签日、锤子、任务、已获得奖杯、演出的选择 |

1 题的答题时间是从接受输入到最后一次正确输入，不含题与题之间的演出和确认对话框。累计的题、格子、答错在题目完成时加算，所以中途结束的未完成题的操作不计入。

还没有统计的保存数据，会用历史里能取得的值来初始化。过去的格数、最大连击等历史里分不出来的值，从 0 开始计量。确认用 URL 不是停止全部保存的功能。具体差别写在下一章。

### 11.2 启动与测试

从仓库根目录，例如可以用下面的命令做静态分发。用显示出来的服务器地址打开 `/app/`。因为使用 ES Modules，不要直接打开 HTML 文件，要用 HTTP 分发。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

使用 Node.js 的测试用下面的命令执行。

```sh
node --test tests/*.test.mjs
```

产品测试是 `tests/app_*.test.mjs` 的 11 个文件、58 项。上面的命令也会包含附带的其他测试，所以总件数会随分发物不同。只显示文件单位件数的 Node.js 环境，在对应环境加上 `--experimental-test-isolation=none` 就可以汇总个别测试。

### 11.3 确认用 URL 参数

像 `/app/?count=6&seed=123` 这样指定。

| 参数 | 行为 |
| --- | --- |
| `count=6`、`count=10`、`count=14` | 启动时选择题数 |
| `seed=<数值>` | 固定题目选择、生成等使用的随机数。不会固定到全部视觉效果的随机数 |
| `extra=<秒>` | 替换加时赛默认的 90 秒。开始时加 900ms 是共同的 |
| `skill=<技能 ID>` | 把通常的题目选择换成那个技能。和复习、固定模板一起用时，选择处理有优先级 |
| `demo` | 从我的等级入口开始固定模板的基础套题。第一题是 27＋35。不进行自动操作 |
| `capture` | 收集声音事件的确认路径。抑制通常的实时声音输出，以及自动引导、标题奖励通知等 |

`skill` 和固定模板的游玩会停止通常的答题时间、成长统计、任务，但做完历史和复习会保存。`skill` 里，如果出题计划是水平测试，计划侧的精通授予和测试完成的保存也会动作。奖杯判定在 `skill` 和 `capture` 会停止，但只指定 `demo` 不会停止。`capture` 下通常的进度、历史、统计保存也会继续。不要把这些当成不留记录的练习功能。
