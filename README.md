# 多帕练习

每做对一道算术题，画面和音乐就会更热闹的计算练习。只在浏览器里运行。

吉祥物「多帕吉」会把你输入的数字搬过去，做对了就给你庆祝。题越往后，画面和声音越热闹，最后会热闹得像过节一样。答错了气势也不会掉下去，也没有游戏结束。

## 特点

- 小学 1～6 年级的 85 个计算技能。一～五年级的计算范围对齐北师大版《义务教育教科书·数学》各年级上、下册；六年级暂沿用最初的安排，尚未对齐教科书。加法、减法、乘法、除法、竖式的中间输入、小数、分数、百分数等
- 「我的等级」模式：从水平测试的结果开始，随着熟练程度解锁下一个技能
- 年级模式、练习、复习、技能树画面
- 全部做对是 100 分。一次做对率达到 80% 以上，可以在限时的加时赛里争取超过 100 分
- 音乐和音效全部用 Web Audio API 合成（没有使用音频文件）
- 支持手机竖屏和电脑。电脑可以用数字键和 Backspace 输入
- 可以在设置里调整动作强度。也可以静音
- 记录全部保存在本机（localStorage），不会发送到外面

## 本地游玩

不需要构建。把 `app/` 当作静态文件提供就能运行。

```bash
python3 -m http.server 8000 -d app
```

在浏览器打开 `http://localhost:8000/`。因为使用了 ES Modules，用 `file://` 直接打开不会运行。

## 测试

需要 Node.js 20 或更高版本。

```bash
node --test tests/*.test.mjs
```
